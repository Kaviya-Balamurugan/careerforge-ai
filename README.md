# CareerForge AI

CareerForge AI is an Agentic AI-powered career planning assistant that helps students and job seekers bridge the gap between their current skills and their dream job.

## Problem

Students often struggle to identify the exact skills, projects, and learning path required for a target role. Existing solutions provide generic advice but lack personalized guidance and continuous progress tracking.

## Solution

CareerForge AI analyzes a user's resume, compares it with real-world job requirements, identifies skill gaps, generates a personalized roadmap, and continuously adapts recommendations based on progress.

## Agent Workflow

### Perceive

* Analyze resume
* Extract skills and projects
* Collect target role requirements

### Decide

* Identify skill gaps
* Prioritize learning objectives

### Act

* Generate personalized roadmap
* Recommend projects and resources

### Observe

* Track progress
* Update recommendations

## Tech Stack

* Frontend: React
* Backend: FastAPI
* AI: Gemini API
* Agent Framework: LangGraph
* Database: SQLite
* Vector Store: ChromaDB
